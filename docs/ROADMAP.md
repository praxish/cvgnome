# Roadmap

The first public release focuses on a reliable local workspace for one job
seeker: profile construction and editing, evidence review, memories, roles,
versioned drafts, and document export. Models remain optional.

Release gates are build reproducibility, tested IPC and recovery behavior,
readable keyboard-accessible UI, accurate platform support, scoped publication,
license notices, and verified distribution artifacts. No gate is satisfied by a
roadmap entry alone; release notes record the checks actually completed.

After the first release, useful directions include:

- Apple Developer ID signing and notarization for easier macOS installation.
- Draft recovery/autosave and protection for Dock Quit and system termination.
- A graphical backup/restore workflow over the tested offline archive format.
- Broader Unicode/font coverage with verified PDF rendering.
- Additional operating systems after native packaging and security testing.
- Smaller feature modules, stronger generated/shared IPC contracts, and more
  frontend regression coverage.
- Better navigation and evidence organization for larger individual workspaces.

Hosted services, billing/activation, multiple-candidate management, employer
screening, and automated application submission are outside the current scope.
Feature requests should explain the individual job-seeker problem and preserve
an offline path for existing functionality.
