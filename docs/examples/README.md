# Synthetic examples

Every person, employer, school, and posting in this directory is fictional.
Use `sample-career.txt` with the first-run document importer, review the extracted
profile, then paste `sample-role.txt` in Roles. Both workflows work without an AI
provider. Extraction is a starting point to review, not a promised exact field
mapping. Do this in a disposable test workspace rather than mixing examples into
your personal career history.

Screenshots or bug reports should use these samples, never a real resume or vault.
