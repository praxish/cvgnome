# Source and asset provenance

CVGnome is a standalone desktop project maintained by `praxish`. The original
author confirmed ownership of the earlier private career-software work from
which some profile validation, compaction, parsing, and rendering concepts were
adapted. The desktop persistence, native application boundary, local review
workflows, and provider integration are maintained in this repository.

This publication grants rights under MPL-2.0 to the covered source and original
assets deliberately included here. It does not publish or license any separate
private repository, service, customer data, credentials, or unpublished work.
The first public repository starts from a reviewed source snapshot; private
development history is not included.

Original project assets include `src/CvGnomeLogo.tsx`, `public/favicon.svg`,
and `src-tauri/icons/cvgnome-app-icon.svg`, with generated platform icons beside
the SVG. Dependencies and their bundled assets retain their own licenses.
The release dependency inventory and notices describe that third-party payload.

Tests and examples must use synthetic identities and reserved example domains.
Do not contribute real resumes, job-search records, provider keys, application
data directories, or screenshots containing personal information. Report any
accidental disclosure privately using SECURITY.md.
